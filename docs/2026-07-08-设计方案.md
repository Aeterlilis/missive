# 墨问 ink-diary —— 设计方案

> 状态：草案 v1 · 日期：2026-07-08

## 目标

在 Boox 墨水屏平板上复刻 riddle 的核心体验：用电磁笔写字 → 停笔后字迹被吸走 → AI 用手写体一笔笔回答 → 淡出。整套软件用网页重写，跑在 Boox 浏览器里。

## 为什么这么选

### 硬件：Boox 而非 reMarkable / 树莓派
- reMarkable Paper Pro 原版要求 OS 3.26–3.27，且 takeover 模式只支持 Paper Pro，门槛高（~$579）。
- 树莓派 + 裸墨水屏最便宜，但**笔的延迟和手感差**——民用裸屏没有自带 EMR 数位层，最现实是"在 Wacom 板上写、在墨水屏上看"，输入输出分离，体验割裂。
- Boox 自带真实压感笔 + 安卓系统 + Chromium 浏览器，软硬件都现成，我们专注写软件。

### 前端：原生 JS 网页而非 React/框架
- Boox 浏览器直接打开即用，无构建步骤。
- 依赖极简（perfect-freehand 一个库），降低墨水屏上的性能负担。
- 后期换硬件（reMarkable、iPad）不用重写。

### 手写动画：Zhang-Suen 细化而非 SVG 路径动画
原版 riddle 用 Dancing Script 渲染 → Zhang-Suen 细化 → trace 成有序笔迹 → 逐点"写"。我们原样移植这套，原因：
- **书写感最真**：细化生成的是单像素中线，动画时像笔尖沿着字心移动。
- SVG `stroke-dashoffset` 描的是字形外轮廓，看起来像在画空心字轮廓，不像在写字。
- Zhang-Suen 是纯整数运算，研究已确认有现成 JS 实现，性能在墨水屏低帧下完全够。

### 字体：霞鹜文楷而非 Dancing Script
- Dancing Script 没有中文字形。
- 霞鹜文楷（LXGW WenKai）开源、覆盖中英文、字形偏细——细化后中线清晰，适合做笔迹动画。
- 视觉上比 Dancing Script 更"工整"，但配合逐点书写动画依然有手写感。

## 状态机 & 时序（移植自 riddle，全部转成 JS 常量）

| 状态 | 触发 | 动作 | 时长 |
|---|---|---|---|
| **聆听 Listening** | 启动 / 上一轮淡出完 | 采集笔迹，监测停笔 | — |
| → 提交 | 停笔 ≥ `IDLE_COMMIT` (2800ms) 且有墨迹 | 截 PNG + 立刻调 AI | 即刻 |
| **饮墨 Drinking** | 提交后 | 哈希溶解淡掉用户字迹（14 段 × 70ms） | ~1s |
| **思考 Thinking** | 饮墨完，AI 还没回 | 中心呼吸点（600ms 闪） | 等 AI |
| **书写 Replying** | AI 首句到达 | scribe.js 逐点书写（26 点/帧 × 14ms） | 按回答长度 |
| **停留 Lingering** | 写完 | 停留展示 | `4000 + 2×字数` ms（≤20s） |
| **淡出 FadingReply** | 停留结束 | 溶解淡掉回答（10 段 × 80ms） + 整页刷新 | ~0.8s |
| → 回到聆听 | — | — | — |

**关键巧思**：提交时**立刻**调 AI，用"饮墨"动画的 ~1s 掩盖首字延迟。riddle 实测首字 ~0.9–1.1s，正好被饮墨盖住。

## 人设：墨先生

冷幽默 + 博学 + 把复杂问题掰开揉碎。完整提示词见 `server/persona.js`。要点：
- 冷幽默但善意，偶尔自嘲/调侃提问者，绝不刻薄
- 用最简单有趣的方式拆解问题，再复杂也讲得像聊天
- 见多识广，顺手抖冷知识
- 回答短（1–3 句），除非对方要详解
- 永不提图像/照片/模型/AI——"你只看得到纸上的字"
- 看不清就说"墨迹晕开了"
- 用写字人的语言回答（写中文用中文回，写英文用英文回）

## 已知风险 & 应对

| 风险 | 应对 |
|---|---|
| Boox 固件 4.1 移除了 A2 低闪模式，HD 模式每次交互全屏闪 | 接受阶段闪屏，动画降到 ~8fps，关键节点主动整页刷新 |
| 墨水屏灰度/半透明残影重 | 全程纯黑白，禁用次像素抗锯齿，`image-rendering: pixelated` |
| 局域网 HTTP 装不了 service worker（PWA 离线） | 不做离线，用"添加到主屏幕"+ manifest 全屏即可 |
| 部分笔报告压感为常数 | 检测压感为常数时，改用笔速推算线宽（速度慢=粗） |
| 中文笔画密，Zhang-Suen 后中线粘连 | trace 时设最小路径长度阈值，丢弃过短碎线 |

## 不在第一版范围

- **记忆功能**（riddle 的 ⟦show:N⟧ 翻页召回）——后续增强
- **多用户/账号**——单机单用户够用
- **离线工作**——依赖大模型 API，本就需联网
- **安卓原生 App**——网页已够，省去维护成本
