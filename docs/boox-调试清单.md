# Boox 真机调试清单

> 拿到 Boox 设备后，按这个清单逐项验证。每项都直接影响体验，别跳过。

## 1. 固件与刷新模式（最关键）

- [ ] **查固件版本**：设置 → 关于 → 固件版本
- [ ] **确认刷新模式**：
  - 固件 < 4.1：有 **A2 模式**（低闪、适合手写/动画）→ 优先用
  - 固件 ≥ 4.1：A2 被移除，只有 **HD 模式**（每次交互全屏闪）→ 接受闪屏，动画降到 ~8fps
- [ ] **E Ink Center 全局设置**：确认它没有覆盖 per-app 配置（设置 → 显示 → E Ink Center）
- [ ] **开启 Deep Refresh + 固定全屏刷新间隔**：减少累积残影

> 若固件已升级且 HD 闪烁难以忍受，可考虑降级固件（有风险，自行权衡），或换用 **EinkBro** 浏览器（开源、e-ink 优化、有刷新按钮）。

## 2. 浏览器与 PWA

- [ ] **内置浏览器能打开** `http://<电脑IP>:3000` 并显示页面
- [ ] **添加到主屏幕**：菜单 → 添加到主屏幕 → 图标出现在桌面
- [ ] **全屏运行**：从桌面图标启动后无浏览器地址栏（manifest `display:fullscreen` 生效）
- [ ] （备选）装 **EinkBro** 测试一遍，对比体验

## 3. 触控笔

- [ ] **压感有值**：在前端调试面板（或 console）看 `e.pressure`，落笔时应 > 0 且随力度变化
- [ ] **若压感是常数**：记下来，改用笔速推算线宽（`ink.js` 已留 fallback 分支）
- [ ] **`getCoalescedEvents()` 有数据**：快速画一笔，看采样点数是否 > 1（平滑度关键）
- [ ] **无 palm rejection 问题**：手掌压屏不应误触发（电磁笔天然不误触，但确认一下）
- [ ] **笔迹延迟可接受**：落笔到墨迹出现 < 50ms 算好

## 4. 网络

- [ ] **Boox 与电脑同一 WiFi/局域网**
- [ ] **电脑防火墙放行 3000 端口**（macOS：系统设置 → 网络 → 防火墙；或临时关防火墙测试）
- [ ] **电脑监听 `0.0.0.0`** 而非 `localhost`（后端已默认）
- [ ] **大模型 API 可达**：从电脑 `curl` 测一次 `/v1/chat/completions`

## 5. 体验调参

到真机后这些常量可能要微调（都在 `web/src/config.js`）：

| 常量 | 默认 | 真机怎么判断 |
|---|---|---|
| `IDLE_COMMIT` | 2800ms | 太短：还没写完就提交；太长：等得心急 |
| 书写速度（点/帧） | 26 | 太快像刷字、太慢像卡顿 |
| 书写帧间隔 | 14ms | 墨水屏刷新跟不上就调大（→ ~80ms/帧） |
| 饮墨段数/间隔 | 14 × 70ms | 残影重就加段数、减慢 |
| 回复字号 | 96px | Boox 10.3" 下确认不挤、不小 |

## 6. 常见问题

- **页面打不开**：确认 IP 对、端口对、防火墙放行；电脑上 `curl http://localhost:3000` 自测
- **提交后无回应**：看后端日志；多半是 API key/模型名/base_url 配错
- **回答不是手写体**：字体没加载上（文楷 ttf 路径/格式问题）
- **书写动画卡/糊**：墨水屏帧率跟不上，调大书写帧间隔、降每帧点数
- **残影重**：增加整页刷新频率；检查是否有半透明元素（应全部纯黑白）
